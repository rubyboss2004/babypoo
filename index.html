歡迎來到寶寶勇士樂譜庫

這裡有老師整理的詩歌譜，給寶寶勇士的樂手練習用。第一次來嗎？花一分鐘看看怎麼用～

怎麼看譜？

點一下歌名就會展開譜面，再點一次收起來。

不好按？可以自己轉調

譜的上方有一排工具：

  • − ／ ＋：升降半音，和弦會立刻全部跟著變
  • ↺：回到原本的調
  • Capo 3　play C：告訴你夾第幾格、用哪個調的指型彈，就能只用好按的和弦
  • A− ／ A＋：字太小可以放大

歌名旁邊有紫色「可轉調」標籤的才能轉調。舊的譜只有圖片，沒有標籤。

如果那首歌同時有圖片版，工具列右邊會出現「圖」，可以切回去看老師原本排好的圖；在圖片版按「文字」再切回來。

怎麼存到手機/電腦？

按譜下面的「下載 / 存到相簿」，會把你現在轉到的那個調存成圖片。

  • 手機：選「儲存圖片」存到相簿
  • 電腦：直接下載

找不到想要的歌？

按上方「我想要新的譜」輸入歌名送出，老師會收到通知。搜尋也可以直接打歌詞找。

把網頁加到主畫面，下次更快打開

iPhone（Safari）
  1. 用 Safari 打開（不要用 LINE 內建瀏覽器）
  2. 按下方中間的「分享」按鈕
  3. 往下捲，選「加入主畫面」
  4. 按右上角「新增」
Android（Chrome）
  1. 用 Chrome 打開
  2. 按右上角「⋮」
  3. 選「加到主畫面」
  4. 按「新增」
電腦（Chrome / Edge）
  1. 網址列右邊找「安裝」圖示
  2. 按下去 → 「安裝」
